# 🐉 Дракончик

Маленькая аркадная игра в стиле Flappy Bird: дракончик летит сквозь скалы, собирает монетки и пытается побить рекорд.

## Запуск

Это статический сайт без зависимостей. Достаточно открыть `index.html` в браузере, либо запустить локальный сервер:

```bash
python3 -m http.server 8000
# затем открой http://localhost:8000
```

## Управление

- **Пробел** / **↑** — взмах крыльев
- **Клик** / **тап по экрану** — взмах крыльев
- **Старт / Заново** — кнопка в оверлее

## Файлы

- `index.html` — разметка и UI
- `style.css` — оформление
- `game.js` — логика игры на Canvas (физика, спавн препятствий, коллизии, частицы)

Лучший счёт сохраняется в `localStorage` и восстанавливается между сессиями.
